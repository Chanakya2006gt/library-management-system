# Alexandria - Library Management System

Comprehensive campus library inventory, real-time circulation desk, automated due date notification engine, and fines settlement portal.

## Agile Scrum Implementation

### Sprint 1: Catalog & Circulation
- **Issue #1**: Catalog Search & Discovery (Search by ISBN, title, and genre)
- **Issue #2**: Book Checkout & Borrow Workflow (Instant stock reservation)
- **Issue #3**: Book Return & Shelf Restock (Automated inventory return)
- **Deliverables**: `index.html`, `style.css`, `app.js`

### Sprint 2: Management & Automation
- **Issue #4**: Automated Due Date & Overdue Notifications (Email/SMS dispatch queue)
- **Issue #5**: Fine Calculation & Payment Management (Daily fine accrual and settlement console)
- **Deliverables**: `fines.html`

## How to Run Locally
Open `index.html` in any web browser or serve with:
```bash
python3 -m http.server 8000
```
